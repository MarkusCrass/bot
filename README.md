# Лунный код — Telegram-бот

Бот на Python с aiogram 3, SQLite, Kerykeion, геокодированием места рождения, Telegram Payments и генерацией персонального PDF-отчёта через OpenAI-compatible API.

## Запуск

1. Нужен Python 3.11+ и системные библиотеки, необходимые WeasyPrint (на Linux обычно `libpango`, `libcairo`, `libgdk-pixbuf`).
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env` и заполните значения. Добавьте бота администратором канала с правом видеть участников; `CHANNEL_ID` должен указывать правильный канал.
4. Убедитесь, что `data/moon_knowledge.json` содержит авторские тексты. В репозитории лежит демонстрационная редакционная заготовка — замените её исходным материалом автора.
5. Запустите: `python bot.py`.

Бот проверяет подписку, последовательно собирает имя, дату, время и город рождения, определяет координаты и временную зону, рассчитывает натальную карту, присылает бесплатный фрагмент, выставляет счёт и после успешной оплаты готовит 18-раздельный PDF. Данные профилей и платежей сохраняются в `data/bot.sqlite3`; отчёты — в `reports/`.

## Импорт авторского текста из PDF

```bash
python scripts/parse_pdf.py author.pdf -o data/moon_knowledge.json
```

Скрипт сначала пробует `pdfplumber`, затем `pypdf`; автоматически распознаёт некоторые заголовки знаков, домов и блока расслабления. Полный извлечённый текст также сохраняется в `source_text`, чтобы его можно было вручную разложить по структуре `signs`, `houses` и `relaxation`. Для сканированного PDF предварительно потребуется OCR.

## Настройки и важные замечания

- `BOT_TOKEN`, `CHANNEL_ID`, `CHANNEL_URL`, `ADMIN_ID`, `PROVIDER_TOKEN`, `GUIDE_PRICE`, `LLM_API_KEY`, `LLM_BASE_URL`; необязательная настройка `LLM_MODEL` поддерживает выбор модели.
- Для реальных платежей настройте провайдера в BotFather. Цена задаётся в рублях, а Telegram invoice получает сумму в копейках.
- Nominatim требует корректный user-agent и умеренную частоту запросов; перед публичным запуском рекомендуется добавить кэширование/ограничение запросов и проверить политику выбранного геокодера.
- Время «12:00» при неизвестном времени рождения — условная оценка: точность дома Луны в таком случае может быть ограничена.
- Астрологические трактовки предназначены для саморефлексии и не являются научной или медицинской диагностикой.
