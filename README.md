# Лунный код — Telegram-бот

Бот на Python с aiogram 3, SQLite, Skyfield, геокодированием места рождения, Telegram Payments и генерацией PDF через fpdf2. Расчёты используют JPL DE421; лунный дом вычисляется в системе равных домов (Ascendant как начало первого дома, по 30° на дом).

## Установка на Windows

Требуется Python 3.11+. В зависимостях нет Kerykeion, PySwissEph, timezonefinder, WeasyPrint или GTK. Skyfield и timezonefinderL распространяются как Python wheels; fpdf2 — чисто Python. На Windows fpdf2 ищет Arial в системной папке шрифтов.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `.env`, добавьте бота администратором канала с правом видеть участников и запустите:

```powershell
python bot.py
```

При первом расчёте Skyfield скачает DE421 (около 17 МБ) в `data/skyfield/`. Для генерации кириллического PDF бот использует Arial из Windows. На Linux/macOS ищет Arial или DejaVu Sans. Для нестандартного расположения шрифта задайте `PDF_FONT_PATH` в `.env`.

## Сценарий и оплата

Бот проверяет подписку, последовательно собирает данные рождения, геокодирует город через Nominatim, определяет часовой пояс через timezonefinderL, рассчитывает знак/дом/аспекты Луны, отправляет бесплатный разбор, принимает Telegram Payments и формирует персональный PDF с 18 разделами.

Если `PROVIDER_TOKEN` заполнен, показывается кнопка реальной оплаты и бот выставляет Telegram invoice. Если он пуст, показывается кнопка **«Оплатить 499 ₽ (Тест)»** (сумма берётся из `GUIDE_PRICE`). Нажатие запускает тестовую генерацию демо-PDF без списания денег и без создания платёжного счёта. Это режим для проверки интерфейса и скриншотов, не тестовый платёж ЮKassa.

- `BOT_TOKEN`, `CHANNEL_ID`, `CHANNEL_URL`, `ADMIN_ID`, `PROVIDER_TOKEN`, `GUIDE_PRICE`, `LLM_API_KEY`, `LLM_BASE_URL`; необязательные `LLM_MODEL`, `PDF_FONT_PATH`.
- Для реальных платежей настройте провайдера через BotFather. Цена указывается в рублях, в Telegram invoice передаётся сумма в копейках.
- Точный часовой пояс зависит от результата геокодирования. Пользователям рекомендуется указывать страну, если названия города неоднозначны.
- Если время рождения неизвестно, бот подставляет 12:00; положение дома в таком случае ориентировочное.
- Данные профилей и платежей хранятся в `data/bot.sqlite3`, ephemeris-файл — в `data/skyfield/`, PDF — в `reports/`.
- Астрологические трактовки предназначены для саморефлексии и не являются медицинской или психологической диагностикой.

## Импорт авторского текста из PDF

```bash
python scripts/parse_pdf.py author.pdf -o data/moon_knowledge.json
```

Скрипт сначала использует `pdfplumber`, затем `pypdf`; распознанные заголовки знаков, домов и блока расслабления раскладываются по разделам. Полный извлечённый текст также сохраняется в `source_text`, чтобы его можно было вручную разметить. Для сканированного PDF предварительно понадобится OCR. Демонстрационные тексты в `data/moon_knowledge.json` следует заменить авторскими.
