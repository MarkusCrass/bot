# Лунный код — Telegram-бот

Бот на Python (aiogram 3) с SQLite, Skyfield/DE421, геокодированием через geopy, часовыми поясами через `timezonefinderL`, Telegram Payments, OpenAI-compatible LLM API и PDF-генерацией на fpdf2.

## Установка и запуск

Требуется Python 3.11+. В зависимостях нет Kerykeion, PySwissEph, `timezonefinder` или WeasyPrint/GTK.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python bot.py
```

Заполните `.env`, добавьте бота администратором канала с правом видеть участников. При первом астрологическом расчёте Skyfield загрузит эфемериды DE421 в `data/skyfield/` (около 17 МБ). Время рождения переводится из локальной временной зоны в UTC; дома рассчитываются в системе равных домов от Асцендента.

Для кириллического PDF fpdf2 использует Arial/Georgia из Windows или DejaVu Sans/Serif на Linux/macOS. Если шрифты находятся нестандартно, задайте `PDF_FONT_PATH`.

## Возможности

- `/start` открывает меню: бесплатный расчёт, описание 18 разделов, сохранённые данные и контакт автора.
- Подписка проверяется перед началом бесплатного расчёта; анкету можно отменить на каждом шаге, использовать сохранённые данные или заполнить заново.
- Бесплатный разбор берёт тексты знака, дома и практик расслабления непосредственно из `data/moon_knowledge.json`; LLM не вызывается.
- Платный отчёт запрашивается у LLM API двумя последовательными частями по девять разделов. Ответ очищается от markdown-обёрток; проверяются состав разделов, точные заголовки и минимум 150 символов текста в каждом разделе. В промпте запрошены два абзаца, разделённые `\n\n`, но формат переносов не влияет на приём ответа. Некорректная часть запрашивается повторно один раз. Если API недоступен или ответ невалиден, бот отправляет PDF из авторских текстов и уведомляет только `ADMIN_ID`.
- При пустом `PROVIDER_TOKEN` кнопка запускает бесплатную тестовую генерацию без платёжного счёта. Реальное списание не происходит. При доступном LLM формируется персональный отчёт, а при сбое — резервный авторский материал; демо-заглушки не создаются.
- Персональный PDF использует изображения и светлую мраморную палитру исходного гайда: тёмно-коричневый текст `#40302B`, заголовки `#654C42`, акценты `#AB958B`. В обложке указываются имя и данные рождения, место, знак, дом и аспекты; затем идут страница содержания и 18 глав.

## Авторский PDF и база знаний

Исходник `author_moon.pdf` находится в корне проекта. Его 111 страниц извлечены в `data/moon_knowledge.json`: 12 знаков (стр. 4–15), 12 домов (стр. 19–30), пять типов аспектов (стр. 31–35), практики расслабления/отдыха (стр. 90–93 и 103) и полный извлечённый текст для справки. Формулировки автора сохраняются без редакторской переписки.

Пересобрать JSON из исходника можно так:

```bash
python scripts/import_author_pdf.py
```

Или указать другой файл/выходной JSON:

```bash
python scripts/import_author_pdf.py author_moon.pdf -o data/moon_knowledge.json
```

Файлы `assets/moon_*` — извлечённые фоновые изображения исходника, используемые PDF-рендерером.

## Настройки и данные

Настройте `BOT_TOKEN`, `CHANNEL_ID`, `CHANNEL_URL`, `ADMIN_ID`, `GUIDE_PRICE` и `LLM_API_KEY`. `PROVIDER_TOKEN` укажите для реальной оплаты — если оставить пустым, доступна только бесплатная тестовая генерация. `LLM_BASE_URL` можно задать для OpenAI-совместимого сервиса; модель задаётся через `LLM_MODEL` (по умолчанию `gpt-4o-mini`). Значения из `.env` загружаются с приоритетом над переменными окружения процесса.

Профили и платежи хранятся в `data/bot.sqlite3`, скачанные эфемериды — в `data/skyfield/`, созданные отчёты — в `reports/`. Астрологические трактовки предназначены для саморефлексии и не являются научной или медицинской диагностикой.
